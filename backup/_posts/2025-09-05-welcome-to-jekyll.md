Welcome to my first Jekyll post! This is an example of how to create blog posts using Jekyll.

Jekyll is a simple, blog-aware, static site generator perfect for GitHub Pages.

## Getting Started

You'll find this post in your `_posts` directory. Go ahead and edit it and re-build the site to see your changes.

## Code Example

Here's how you can include code in your posts:

```ruby
def print_hi(name)
  puts "Hi, #{name}"
end
print_hi('Tom')
#=> prints 'Hi, Tom' to STDOUT.
```
